## Potential Issue
In 2026, Pascal Lauer <lauer@cs.uni-saarland.de> observed that instances of this domain involving at least a block on level 6 of the world are likely unsolvable.
Reachability in this domain is defined by the generator to reach only 5 levels up -- and there is no way for the player to move up from level 0 of the world.

So far, only the planner by Pascal Lauer has confirmed that these instances are unsolvable.
Planners in the IPC did not find a plan, nor reported any type of unsolvability -- as all ran out of time or memory.

This issue has not been solved conclusively. We will update information once it has been resolved.
